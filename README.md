Proyecto Web Atalanta
Descripción del proyecto:
En esta primera versión del proyecto hemos desarrollado los archivos HTML, CSS y JavaScript necesarios para crear la base de una nueva versión de la página web de la empresa Atalanta.
El objetivo principal de esta fase ha sido construir la estructura inicial de la web y preparar el proyecto para futuras mejoras y funcionalidades.
 
Cambios realizados:
En comparación con la página original de la empresa, se han realizado únicamente los cambios indispensables. Estos cambios se han centrado principalmente en:
Corrección de algunos errores de diseño.
Mejora visual de ciertos elementos de la página.
Organización básica del código para facilitar el desarrollo futuro.
 
 
Tecnologías utilizadas:
HTML
CSS
JavaScript
 
Estado del proyecto:
Esta versión corresponde a la primera semana de desarrollo. Consideramos que se han cumplido los objetivos principales planteados para esta fase inicial del proyecto.
